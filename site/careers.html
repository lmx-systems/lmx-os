Careers

Real-time systems, running on real operations.

Most optimization problems are simulations. Ours has vehicles and loading docks in it.

LMX is small and early. The work is a live dispatch system making decisions every few seconds against physical constraints that do not negotiate — traffic, loading time, a site that closes at noon on Saturdays, a vehicle that won't start.

If you want a problem where correctness is measured by whether the delivery arrived, this is one.

What makes it hard
Every new order changes the optimal plan for the entire fleet, and the plan has to be re-solved inside a few seconds while drivers are moving.
Deliberately delaying work to batch it is only safe if you know precisely how much time each order has left. Getting that wrong misses a commitment.
The mobile side has to keep working when the phone loses signal in a parking garage.
The same dispatch logic has to hold when some of the fleet is not human-driven.
